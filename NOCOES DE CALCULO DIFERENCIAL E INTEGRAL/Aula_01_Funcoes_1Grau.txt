================================================================================
CONCEITO FUNDAMENTAL
================================================================================

IMPORTÂNCIA DAS FUNÇÕES
────────────────────────────────────────────────────────────────────────────

A função é uma importante ferramenta da matemática para análise das relações
entre grandezas.

As relações podem ser descritas por meio de:
  • Fórmulas
  • Gráficos
  • Palavras
  • Dados numéricos resultantes de observações e medições


EXEMPLOS DE APLICAÇÃO
────────────────────────────────────────────────────────────────────────────
  • O tempo gasto para percorrer determinado trajeto depende da velocidade
  • O valor gasto na conta de luz depende do consumo
  • A quantidade de poluentes na atmosfera depende da quantidade de veículos
  • A qualidade da água depende da quantidade de poluentes
  • O tamanho de certa população depende do tempo
  • O custo de produção depende da quantidade produzida
  • A quantidade demanda de um produto varia em função de seu preço
  • O lucro de uma empresa depende da quantidade vendida e do preço praticado

================================================================================
DEFINIÇÃO DE FUNÇÃO
================================================================================

CONCEITO MATEMÁTICO
────────────────────────────────────────────────────────────────────────────

Uma relação f : A → B é denominada uma função de A em B (nessa ordem) se
a cada elemento de A corresponde um único elemento de B.


COMPONENTES DE UMA FUNÇÃO
────────────────────────────────────────────────────────────────────────────

Domínio [D(f)]:
  Conjunto A - conjunto dos valores de entrada (x)

Contradomínio [CD(f)]:
  Conjunto B - conjunto que contém os possíveis valores de saída

Imagem [Im(f)]:
  Subset do contradomínio - valores efetivamente mapeados pela função


NOTAÇÃO
────────────────────────────────────────────────────────────────────────────
  f : A → B onde y = f(x)
  
  x = variável independente (entrada)
  y = variável dependente (saída)

================================================================================
FUNÇÃO DO 1º GRAU (LINEAR)
================================================================================

DEFINIÇÃO
────────────────────────────────────────────────────────────────────────────

Uma função do 1º grau é toda função f: ℝ → ℝ que pode ser escrita na forma:

    f(x) = ax + b

Onde:
  • a e b são números reais
  • a ≠ 0 (se a = 0, não é função de 1º grau)


CARACTERÍSTICAS GRÁFICAS
────────────────────────────────────────────────────────────────────────────

  • O gráfico de uma função de 1º grau é sempre uma RETA
  • Se a > 0 → função CRESCENTE
  • Se a < 0 → função DECRESCENTE


COEFICIENTES
────────────────────────────────────────────────────────────────────────────

Coeficiente Angular (a):
  • Indica a taxa de variação da função
  • Se a = 2: um acréscimo de 1 unidade em x acarreta acréscimo de 2 em y
  • Se a = -2: um acréscimo de 1 unidade em x acarreta decréscimo de 2 em y
  • Também é chamado de "slope" ou inclinação da reta

Coeficiente Linear (b):
  • É o intercepto no eixo y
  • É o ponto onde a reta cruza o eixo vertical
  • Coordenada: (0, b)


PONTOS IMPORTANTES DO GRÁFICO
────────────────────────────────────────────────────────────────────────────

Raiz da função (ou zero da função):
  Valor de x tal que f(x) = 0
  
  Cálculo: ax + b = 0
           x = -b/a
  
  Coordenada: (-b/a, 0)

Intersecção com eixo y:
  Coordenada: (0, b)

Intersecção com eixo x (raiz):
  Coordenada: (-b/a, 0)

================================================================================
EXEMPLOS PRÁTICOS
================================================================================

EXEMPLO 1: Esboçar gráficos
────────────────────────────────────────────────────────────────────────────

a) f(x) = 3x + 1
   
   Pontos para traçado:
   • Para x = 0: f(0) = 1 → Ponto (0, 1)
   • Para x = 2: f(2) = 7 → Ponto (2, 7)
   
   Características:
   • a = 3 > 0 → Função CRESCENTE
   • b = 1 → Intercepta eixo y em (0, 1)
   • Raiz: x = -1/3 → Intercepta eixo x em (-1/3, 0)


b) f(x) = -3x + 1
   
   Pontos para traçado:
   • Para x = 0: f(0) = 1 → Ponto (0, 1)
   • Para x = 2: f(2) = -5 → Ponto (2, -5)
   
   Características:
   • a = -3 < 0 → Função DECRESCENTE
   • b = 1 → Intercepta eixo y em (0, 1)
   • Raiz: x = 1/3 → Intercepta eixo x em (1/3, 0)


EXEMPLO 2: Calcular valores da função
────────────────────────────────────────────────────────────────────────────

Seja f(x) = 2x + 4, calcule:

a) f(10) = 2(10) + 4 = 20 + 4 = 24

b) f(2) = 2(2) + 4 = 4 + 4 = 8

c) O valor de x tal que f(x) = 10
   2x + 4 = 10
   2x = 6
   x = 3

d) O valor de x tal que f(x) = 2
   2x + 4 = 2
   2x = -2
   x = -1


EXEMPLO 3: Determinar função a partir de gráfico
────────────────────────────────────────────────────────────────────────────

Dado um gráfico com dois pontos conhecidos, determinar f(x) = ax + b:

1. Usar a fórmula de dois pontos: a = (y₂ - y₁)/(x₂ - x₁)
2. Substituir em f(x) = ax + b para encontrar b
3. Escrever a função completa


EXEMPLO 4: Reta com coeficiente angular específico
────────────────────────────────────────────────────────────────────────────

Escreva a equação da reta y = ax + b com:
  • Coeficiente angular = 1/2
  • Intersecção com eixo y = 3

Resposta: y = (1/2)x + 3


EXEMPLO 5: Função através de dois pontos
────────────────────────────────────────────────────────────────────────────

Obtenha a função linear cujo gráfico passa pelos pontos (1, 2) e (3, 8).

Solução:
  a = (8 - 2)/(3 - 1) = 6/2 = 3
  
  Substituindo em f(x) = 3x + b:
  2 = 3(1) + b
  2 = 3 + b
  b = -1
  
  Resposta: f(x) = 3x - 1

PROBLEMA 1: Movimento com velocidade linear
────────────────────────────────────────────────────────────────────────────

Um certo móvel está se deslocando com velocidade em função do tempo expressa
por: v = at + b

Dado:
| Instante (s) | Velocidade (m/s) |
|      3       |       45         |
|      5       |       35         |

Encontrar:
  a) Taxa de variação da velocidade em função do tempo
  b) Expressão da função velocidade
  c) Gráfico mostrando intersecções com os eixos

Solução:
  a = (35 - 45)/(5 - 3) = -10/2 = -5 m/s²
  
  v = -5t + b
  45 = -5(3) + b
  45 = -15 + b
  b = 60
  
  Resposta: v(t) = -5t + 60


PROBLEMA 2: Locadora de carros
────────────────────────────────────────────────────────────────────────────

Locadora A: Taxa fixa R$ 50,00 + R$ 0,30 por km
Locadora B: Taxa fixa R$ 20,00 + R$ 0,35 por km

a) Função para cada locadora:
   A: f(x) = 50 + 0,30x
   B: g(x) = 20 + 0,35x

b) Se paguei R$ 124,00 na locadora A, quantos km rodei?
   124 = 50 + 0,30x
   74 = 0,30x
   x ≈ 246,67 km

c) Se rodei 145 km na locadora B, quanto devo pagar?
   g(145) = 20 + 0,35(145)
   g(145) = 20 + 50,75
   g(145) = R$ 70,75

d) A partir de que quilometragem A fica mais vantajosa que B?
   50 + 0,30x = 20 + 0,35x
   30 = 0,05x
   x = 600 km
   
   Resposta: A partir de 600 km


PROBLEMA 3: Depreciação de equipamento
────────────────────────────────────────────────────────────────────────────

Um laboratório investiu US$ 81.000,00 em um equipamento. Usa método de linha
reta para depreciação. Após 30 anos, o valor será zero.

Encontrar:
  a) Função y = ax + b de depreciação
  b) Preço do equipamento após 5 anos
  c) Tempo para o preço chegar a US$ 48.500,00

Solução:
  Pontos: (0, 81000) e (30, 0)
  
  a = (0 - 81000)/(30 - 0) = -2700
  
  y = -2700x + 81000
  
  b) Após 5 anos: y(5) = -2700(5) + 81000 = US$ 67.500,00
  
  c) Quando y = 48.500:
     48500 = -2700x + 81000
     -32500 = -2700x
     x ≈ 12,04 anos


PROBLEMA 4: Salário do vendedor
────────────────────────────────────────────────────────────────────────────

Um vendedor ganha:
  • Salário fixo: R$ 1.500,00
  • Comissão: R$ 25,00 por assinatura vendida

Expresse seu salário S como função de x (número de assinaturas/mês):

Resposta: S(x) = 1500 + 25x

================================================================================
RESUMO - FUNÇÃO DO 1º GRAU
================================================================================

Forma geral: f(x) = ax + b, onde a ≠ 0

Gráfico: Sempre uma reta

Classificação:
  • a > 0: Crescente (reta sobe da esquerda para direita)
  • a < 0: Decrescente (reta desce da esquerda para direita)

Pontos importantes:
  • Intersecção y: (0, b)
  • Intersecção x (raiz): (-b/a, 0)

Aplicações: Custos, receitas, velocidade, depreciação, etc.
