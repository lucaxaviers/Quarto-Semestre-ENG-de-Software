## 📋 EMENTA

Apresenta conceitos, aplicações e interpretações gráficas de **limites**, **derivada** e **integral**, com ênfase na integração numérica, com uso de software computacional.

### Conteúdos Principais:

- Limite

## 📊 AVALIAÇÃO

### Instrumentos de Avaliação:
- **P1 e P2**: Duas provas individuais e presenciais (0-10 pontos)
- **A**: Atividades (0-10 pontos) - média aritmética

### Fórmula de Cálculo:

$$MF = 0,35 \times P1 + 0,50 \times P2 + 0,15 \times A$$

Onde:
- P1 = Prova 1 (35%)
- P2 = Prova 2 (50%)
- A = Média de Atividades (15%)

### Recuperação:
- **P3**: Prova de recuperação para MF < 5,0
- Substitui a menor nota entre P1 e P2
- **Requisito**: Mínimo 75% de frequência

### Datas das Avaliações:
- 📅 **P1 (35%)** - 29/09/2026
- 📅 **P2 (50%)** - 24/11/2026
- 📅 **P3 (Recuperação)** - 01/12/2026
